# Transformation Health — Homepage

A redesigned, conversion-ready homepage for **Transformation Health, LLC**, a behavioral-health provider serving Baltimore City and Odenton, Maryland.

Individualized mental health, substance use recovery, and psychiatric rehabilitation services for children, adolescents, adults, and families across Maryland — in person and via telehealth.

## Stack
- Single-file static site (`index.html`) — semantic HTML, modern CSS, vanilla JS. No build step, no dependencies.
- Google Fonts: Fraunces (display) + Inter (body).
- Optimized local imagery in `assets/images/` (no hotlinked URLs).

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
python3 -m http.server 8080
# visit http://localhost:8080
```

## Design system
- **Deep navy** headings/high-trust areas · **refined healthcare blue** primary actions · **soft ivory** section backgrounds · **muted gold** heritage accent · **sage** supportive accent · **charcoal** body text.
- Accessible: skip link, semantic landmarks, single `<h1>`, keyboard-accessible menus, visible focus states, `prefers-reduced-motion` respected, lazy-loaded below-the-fold images, no layout shift.
